# Deployment Guide

## Website Integration
1. In Dialogflow: Integrations → Web Demo
2. Enable and copy iframe code
3. Add to website HTML before `</body>`

## Facebook Messenger
1. Create Facebook Page
2. In Dialogflow: Integrations → Facebook Messenger
3. Follow connection steps

## Requirements
- Dialogflow ES (free tier)
- Website with HTML access
- Basic knowledge of web hosting
