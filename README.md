# Fitness Center FAQ Chatbot

Dialogflow chatbot for gym member inquiries.

## Features
- Class schedule information
- Equipment usage instructions
- Membership policy answers
- Personal trainer matching
- Locker rental info
- Guest policies

## Agent Structure
- **Intents**: 6+ FAQ categories
- **Entities**: Equipment names, trainer names
- **Responses**: Pre-defined answers with facility info

## Setup
1. Import `agent.zip` into Dialogflow
2. Train with your specific gym data
3. Deploy via Web Demo or Messenger

## How to Update
1. Make changes in Dialogflow console
2. Export agent as ZIP
3. Replace files in this repo
4. Commit with descriptive message
